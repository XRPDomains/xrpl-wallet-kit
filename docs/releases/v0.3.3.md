# v0.3.3

- **Clasp wallet:** new opt-in `@xrpl-wallet-kit/adapter-clasp` for XRPL Mainnet and Testnet. Connect with passkeys, sign transactions without broadcasting, or sign and submit through the wallet.
- **Reliable requests:** cancellation and timeout cleanup, explicit reconnects, late-reply protection and no automatic submission retries.
- **Clear transaction outcomes:** preserve transaction hashes and distinguish user rejection, confirmed failures and unknown submission results.
- **Documentation:** Clasp setup, Payment/NFT examples and updated supported-wallet tables. Clasp remains a standalone adapter, outside the default client/browser wallet list.
