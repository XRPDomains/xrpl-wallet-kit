# XRPL Wallet Kit 0.1.22

## GhostSig Improvements

- Omitted or undefined `SourceTag` defaults to `0` on a clone of `txJson`.
  The same normalized transaction is sent and checked against the signed blob.
  The dApp's original object is unchanged, explicit uint32 tags are preserved,
  and invalid or wallet-modified tags remain rejected.
- Connect and signing popups are widened from 420 to 560 px, keeping 720 px
  height, resizing and scrolling. Browsers may adapt dimensions on small screens.
- Applies to sign-only, `submit: false` and sign-and-submit requests.

## Live Testing And Documentation

On 2026-10-13, the maintainer reported that documented GhostSig and Ledger
transaction commands passed in their setup. This is scoped to the tested
environment, not a guarantee for every firmware or network. Batch acceptance
still requires separate live testing; Ledger Batch support is not confirmed.

Package versions, website navigation and adapter guides are synchronized to
0.1.22. Existing dApps supplying `SourceTag` do not need to change their payloads.

Release validation uses focused GhostSig regression tests, package/browser smoke
checks and the website production build. Publication is confirmed by successful
npm and GitHub responses, without waiting for CDN/cache propagation.
