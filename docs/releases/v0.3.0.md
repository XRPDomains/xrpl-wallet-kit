# v0.3.0

- Add the native **Joey Wallet** browser extension adapter (`joey-wallet`) with XRPL Mainnet, Testnet and Devnet support, passive session restore, sign-only and sign-and-submit.
- Add wallet-native `signIn()` with Joey CAIP-122 and Ledger challenge proofs, request cancellation and a server verifier with one-time nonce consumption. Existing `signMessage()` and authentication flows are unchanged.
- Reduce Xahau signing latency with parallel RPC reads and combined post-sign validation/submission, while retaining intent, fee, expiry and session checks.
- Update wallet and authentication documentation; remove Otsu from public wallet listings and local examples.
