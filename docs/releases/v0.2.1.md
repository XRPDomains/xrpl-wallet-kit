# XRPL Wallet Kit 0.2.1

## Wallet UI

- Show the selected chain and network beside the modal footer branding, including
  XRPL Mainnet and Xahau Mainnet, without adding a mainnet badge.
- Improve Installed badge discovery for late-injected extensions. Availability
  checks allow more time, refresh while the picker is open and retain a previous
  positive result when a passive probe times out. Explicit unavailable results
  still clear the badge; availability is not connection or authentication.

## Xahau Runtime

- Fully minify the standalone browser runtime, including ESM whitespace.
  The asset is approximately 267 KB uncompressed / 87 KB gzip, down from
  approximately 394 KB / 109 KB gzip. It remains loaded only when needed.
- Keep the same `xrpl-wallet-kit-xahau.runtime.js` filename and signing API.
  When self-hosting, update the base IIFE and runtime together to the same version.

## Website and Integration Docs

- Add a dedicated Xahau Network page with interactive wallet connection,
  Mainnet/Testnet selection, compact UI controls and copyable transaction examples.
- Open Theme Builder directly on Xahau with `?chain=xahau`.
- Add a fallback CDN for SDK resource-loading failures and readable preview errors.
- Update Xahau Payment, Invoke/HookParameters, URIToken and read-only state examples;
  align wallet capabilities and remove internal test checklists from consumer guides.
- Extend the adapter developer skill with chain declarations, protocol-aware
  signing, provider network verification and XRP/XAH hardware app selection.

Xahau supports Xaman, GemWallet, Xyra and explicitly enabled Ledger through the
existing single-sign transaction API. SetHook, Batch and multisign on Xahau
remain outside the supported scope. No new transaction support is implied by
these UI and runtime improvements.

All Wallet Kit packages use version 0.2.1. Update pinned packages together.
